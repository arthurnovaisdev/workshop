# Workshop Web Services

Projeto desenvolvido em um workshop de **Web Services**, utilizando Java e Spring Boot para criação de uma API REST.

## 🛠️ Tecnologias

* Java
* Spring Boot
* Spring Web
* Spring Data JPA
* H2 Database
* PostgreSQL
* Neon
* Render

## 🗄️ Banco de Dados

O **H2** é utilizado para testes/desenvolvimento local, enquanto o **PostgreSQL**, hospedado no **Neon**, é utilizado em produção.

## ☁️ Deploy

A aplicação é hospedada no **Render**, conectada ao banco PostgreSQL do Neon.

## 🎯 Objetivo

Praticar o desenvolvimento de APIs REST com **Java + Spring Boot**, integração com banco de dados e deploy em nuvem.
